# Asset Pipeline Infrastructure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the project its first real art — a procedurally generated neo-brutalist UI sprite, four procedurally generated sport-prop icons, and a real RivalRunner character sprite sourced from a CC0 pack — with correct Unity import settings and, for the one externally sourced asset, a license credit.

**Architecture:** Three independent Editor-tooling branches, each producing committed, already-imported assets: (1) a `Texture2D`-drawing generator for one reusable neo-brutalist button sprite (2) a `Texture2D`-drawing generator for four prop icons (3) a one-time download → Python recolor → Unity import → prefab-wire sequence for RivalRunner. All Editor code runs via Unity CLI batchmode (`-executeMethod`), matching the existing `GenerateTask1Fonts.cs` / `BuildScript.cs` precedent. Verification is `EditMode` tests asserting the generated/imported assets exist with correct import settings — this environment has no Editor GUI, so visual correctness is out of reach and is called out explicitly, not silently skipped.

**Tech Stack:** Unity `6000.3.23f1` Editor scripting (`UnityEditor.TextureImporter`, `AssetDatabase`), NUnit via Unity Test Framework, Python 3 + Pillow (already installed, verified `12.3.0`) for the one raster recolor step, `curl`/`unzip` for the one CC0 download.

**Spec:** `docs/superpowers/specs/2026-09-03-asset-pipeline-design.md`

## Global Constraints

- Corner radius = `24` and border width = `4` — read from `Assets/_Project/Settings/UI/UITheme.asset` (`KMA.Gameplay.UI.UITheme.CornerRadius` / `.BorderWidth`) at generation time, never hardcoded, since the asset already owns these values.
- Sprite pixels-per-unit = `100` for every new sprite (project-wide convention, `PLAN.md` §7).
- Texture compression: `ASTC_4x4` for UI and prop-icon textures ("UI sắc nét"), `ASTC_6x6` for the RivalRunner character texture ("art") — `PLAN.md` §6 texture budget line.
- Only CC0-licensed external sources may be copied into the repo, and `Assets/_Project/CREDITS.md` must be updated in the same commit that adds the file(s) it documents.
- No sprite/texture may be downloaded for UI or prop icons — those are procedurally generated by Editor code, per the approved design (§4.1–4.2 of the spec).
- Unity batchmode invocation: `rtk proxy "$KMA_UNITY_EDITOR" -batchmode -projectPath . -executeMethod <Type>.<Method> -quit -logFile <path>.log`. Test invocation: `rtk proxy "$KMA_UNITY_EDITOR" -batchmode -projectPath . -runTests -testPlatform EditMode -testFilter <ClassName> -testResults <path>.xml -logFile <path>.log -quit` (`README.md` §Run tests, `docs/qa/s6-sprint-device-gate.md`). `$KMA_UNITY_EDITOR` must be exported before running any step below.

```csharp
using System.IO;
using KMA.Gameplay.UI;
using UnityEditor;
using UnityEngine;

internal static class GenerateBrutalUISprites
{
    private const string OutputDirectory = "Assets/_Project/Art/UI/Generated";
    private const string OutputPath = OutputDirectory + "/ButtonBrutal.png";
    private const string ThemePath = "Assets/_Project/Settings/UI/UITheme.asset";
    private const int TextureSize = 80;

    public static void Run()
    {
        var theme = AssetDatabase.LoadAssetAtPath<UITheme>(ThemePath);
        if (theme == null)
            throw new FileNotFoundException("UITheme asset not found", ThemePath);

        Directory.CreateDirectory(OutputDirectory);
        var texture = BuildTexture(theme);
        File.WriteAllBytes(OutputPath, texture.EncodeToPNG());
        Object.DestroyImmediate(texture);

        AssetDatabase.ImportAsset(OutputPath, ImportAssetOptions.ForceUpdate);
        ConfigureImporter(theme);
        AssetDatabase.Refresh();
        Debug.Log($"Generated procedural UI sprite at {OutputPath}.");
    }

    private static Texture2D BuildTexture(UITheme theme)
    {
        var cornerRadius = Mathf.Max(1f, theme.CornerRadius);
        var borderWidth = Mathf.Max(1f, theme.BorderWidth);
        var border = theme.Border;
        var borderColor = new Color32(
            (byte)Mathf.RoundToInt(border.r * 255f),
            (byte)Mathf.RoundToInt(border.g * 255f),
            (byte)Mathf.RoundToInt(border.b * 255f),
            255);

        var texture = new Texture2D(TextureSize, TextureSize, TextureFormat.RGBA32, false)
        {
            filterMode = FilterMode.Bilinear,
            wrapMode = TextureWrapMode.Clamp
        };
        var half = TextureSize / 2f;
        var pixels = new Color32[TextureSize * TextureSize];
        for (var y = 0; y < TextureSize; y++)
        {
            for (var x = 0; x < TextureSize; x++)
            {
                var px = x + 0.5f;
                var py = y + 0.5f;
                var qx = Mathf.Max(Mathf.Abs(px - half) - (half - cornerRadius), 0f);
                var qy = Mathf.Max(Mathf.Abs(py - half) - (half - cornerRadius), 0f);
                var dist = Mathf.Sqrt(qx * qx + qy * qy) - cornerRadius;

                Color32 pixel;
                if (dist > 0f)
                    pixel = new Color32(0, 0, 0, 0);
                else if (dist > -borderWidth)
                    pixel = borderColor;
                else
                    pixel = new Color32(255, 255, 255, 255);
                pixels[(y * TextureSize) + x] = pixel;
            }
        }
        texture.SetPixels32(pixels);
        texture.Apply();
        return texture;
    }

    private static void ConfigureImporter(UITheme theme)
    {
        var importer = (TextureImporter)AssetImporter.GetAtPath(OutputPath);
        importer.textureType = TextureImporterType.Sprite;
        importer.spriteImportMode = SpriteImportMode.Single;
        importer.spritePixelsPerUnit = 100f;
        importer.filterMode = FilterMode.Bilinear;
        importer.mipmapEnabled = false;

        var border = Mathf.RoundToInt(theme.CornerRadius + theme.BorderWidth);
        importer.spriteBorder = new Vector4(border, border, border, border);

        var platformSettings = importer.GetPlatformTextureSettings("Android");
        platformSettings.overridden = true;
        platformSettings.format = TextureImporterFormat.ASTC_4x4;
        importer.SetPlatformTextureSettings(platformSettings);

        EditorUtility.SetDirty(importer);
        importer.SaveAndReimport();
    }
}
```

```csharp
using System;
using System.IO;
using KMA.Gameplay.UI;
using UnityEditor;
using UnityEngine;

internal static class GeneratePropIcons
{
    private const string OutputDirectory = "Assets/_Project/Art/Props/Generated";
    private const string ThemePath = "Assets/_Project/Settings/UI/UITheme.asset";
    private const int TextureSize = 64;

    public static void Run()
    {
        var theme = AssetDatabase.LoadAssetAtPath<UITheme>(ThemePath);
        if (theme == null)
            throw new FileNotFoundException("UITheme asset not found", ThemePath);

        Directory.CreateDirectory(OutputDirectory);
        Bake("ShuttlecockIcon", Shuttlecock, theme);
        Bake("PingPongIcon", PingPong, theme);
        Bake("SwimmingIcon", Swimming, theme);
        Bake("PushUpsIcon", PushUps, theme);
        AssetDatabase.Refresh();
        Debug.Log("Generated 4 procedural prop icons.");
    }

    private static void Bake(string name, Func<float, float, float, bool> insideTest, UITheme theme)
    {
        var assetPath = $"{OutputDirectory}/{name}.png";
        var texture = BuildTexture(insideTest, theme);
        File.WriteAllBytes(assetPath, texture.EncodeToPNG());
        Object.DestroyImmediate(texture);
        AssetDatabase.ImportAsset(assetPath, ImportAssetOptions.ForceUpdate);
        ConfigureImporter(assetPath);
    }

    private static Texture2D BuildTexture(Func<float, float, float, bool> insideTest, UITheme theme)
    {
        var borderWidth = Mathf.Max(1f, theme.BorderWidth);
        var borderColor = ToColor32(theme.Border);
        var fillColor = ToColor32(theme.Accent);

        var texture = new Texture2D(TextureSize, TextureSize, TextureFormat.RGBA32, false)
        {
            filterMode = FilterMode.Bilinear,
            wrapMode = TextureWrapMode.Clamp
        };
        var pixels = new Color32[TextureSize * TextureSize];
        for (var y = 0; y < TextureSize; y++)
        {
            for (var x = 0; x < TextureSize; x++)
            {
                var px = x + 0.5f;
                var py = y + 0.5f;
                Color32 pixel;
                if (insideTest(px, py, 0f))
                    pixel = fillColor;
                else if (insideTest(px, py, borderWidth))
                    pixel = borderColor;
                else
                    pixel = new Color32(0, 0, 0, 0);
                pixels[(y * TextureSize) + x] = pixel;
            }
        }
        texture.SetPixels32(pixels);
        texture.Apply();
        return texture;
    }

    private static Color32 ToColor32(Color color) => new Color32(
        (byte)Mathf.RoundToInt(color.r * 255f),
        (byte)Mathf.RoundToInt(color.g * 255f),
        (byte)Mathf.RoundToInt(color.b * 255f),
        255);

    private static void ConfigureImporter(string assetPath)
    {
        var importer = (TextureImporter)AssetImporter.GetAtPath(assetPath);
        importer.textureType = TextureImporterType.Sprite;
        importer.spriteImportMode = SpriteImportMode.Single;
        importer.spritePixelsPerUnit = 100f;
        importer.filterMode = FilterMode.Bilinear;
        importer.mipmapEnabled = false;

        var platformSettings = importer.GetPlatformTextureSettings("Android");
        platformSettings.overridden = true;
        platformSettings.format = TextureImporterFormat.ASTC_4x4;
        importer.SetPlatformTextureSettings(platformSettings);

        EditorUtility.SetDirty(importer);
        importer.SaveAndReimport();
    }

    private static bool InsideCircle(float x, float y, float cx, float cy, float r, float expand)
        => ((x - cx) * (x - cx)) + ((y - cy) * (y - cy)) <= (r + expand) * (r + expand);

    private static bool InsideRect(float x, float y, float minX, float minY, float maxX, float maxY, float expand)
        => x >= minX - expand && x <= maxX + expand && y >= minY - expand && y <= maxY + expand;

    private static bool Shuttlecock(float x, float y, float expand)
    {
        var half = TextureSize / 2f;
        var corkInside = InsideCircle(x, y, half, half - 18f, 8f, expand);
        var skirtTopY = half - 10f;
        var skirtBottomY = half + 20f;
        if (y < skirtTopY - expand || y > skirtBottomY + expand)
            return corkInside;
        var t = Mathf.Clamp01((y - skirtTopY) / (skirtBottomY - skirtTopY));
        var halfWidth = Mathf.Lerp(6f, 16f, t) + expand;
        var skirtInside = Mathf.Abs(x - half) <= halfWidth;
        return corkInside || skirtInside;
    }

    private static bool PingPong(float x, float y, float expand)
    {
        var bladeInside = InsideCircle(x, y, TextureSize * 0.38f, TextureSize * 0.55f, 14f, expand);
        var handleInside = InsideRect(x, y, TextureSize * 0.34f, TextureSize * 0.72f, TextureSize * 0.44f, TextureSize * 0.88f, expand);
        var ballInside = InsideCircle(x, y, TextureSize * 0.74f, TextureSize * 0.28f, 6f, expand);
        return bladeInside || handleInside || ballInside;
    }

    private static bool Swimming(float x, float y, float expand)
    {
        var strokeHalf = 3f + expand;
        return NearWave(x, y, TextureSize * 0.36f, strokeHalf) || NearWave(x, y, TextureSize * 0.62f, strokeHalf);
    }

    private static bool NearWave(float x, float y, float baseline, float strokeHalf)
    {
        var wave = baseline + (Mathf.Sin(x / TextureSize * Mathf.PI * 2f) * 6f);
        return Mathf.Abs(y - wave) <= strokeHalf;
    }

    private static bool PushUps(float x, float y, float expand)
    {
        var barInside = InsideRect(x, y, TextureSize * 0.2f, TextureSize * 0.46f, TextureSize * 0.8f, TextureSize * 0.54f, expand);
        var leftPlate = InsideRect(x, y, TextureSize * 0.14f, TextureSize * 0.3f, TextureSize * 0.22f, TextureSize * 0.7f, expand);
        var rightPlate = InsideRect(x, y, TextureSize * 0.78f, TextureSize * 0.3f, TextureSize * 0.86f, TextureSize * 0.7f, expand);
        return barInside || leftPlate || rightPlate;
    }
}
```

- [ ] **Step 3: Write the recolor script**

```python
#!/usr/bin/env python3
"""Recolor the outfit of a Kenney Toon Characters frame to a target RGB color.

Only pixels close to the sampled source outfit color are changed, so skin,
hair, and shoes are left untouched. Usage:
    recolor_character.py <src.png> <dst.png> <r> <g> <b>
"""
import sys
from PIL import Image

OUTFIT_REFERENCE = (99, 102, 190)
THRESHOLD = 60


def recolor_outfit(src_path, dst_path, target_rgb):
    img = Image.open(src_path).convert("RGBA")
    pixels = img.load()
    for y in range(img.height):
        for x in range(img.width):
            r, g, b, a = pixels[x, y]
            if a == 0:
                continue
            if (abs(r - OUTFIT_REFERENCE[0]) < THRESHOLD
                    and abs(g - OUTFIT_REFERENCE[1]) < THRESHOLD
                    and abs(b - OUTFIT_REFERENCE[2]) < THRESHOLD):
                pixels[x, y] = (target_rgb[0], target_rgb[1], target_rgb[2], a)
    img.save(dst_path)


if __name__ == "__main__":
    if len(sys.argv) != 6:
        raise SystemExit("usage: recolor_character.py <src.png> <dst.png> <r> <g> <b>")
    src, dst, r, g, b = sys.argv[1:]
    recolor_outfit(src, dst, (int(r), int(g), int(b)))
```

```csharp
using UnityEditor;
using UnityEngine;

internal static class ImportRivalRunnerSprite
{
    private const string SpritePath = "Assets/_Project/Art/Characters/RivalRunner/RivalRunner.png";
    private const string PrefabPath = "Assets/_Project/Prefabs/Gameplay/RivalRunner.prefab";

    public static void Run()
    {
        AssetDatabase.ImportAsset(SpritePath, ImportAssetOptions.ForceUpdate);
        ConfigureImporter();
        AssetDatabase.Refresh();
        WireIntoPrefab();
        Debug.Log($"Imported and wired {SpritePath} into {PrefabPath}.");
    }

    private static void ConfigureImporter()
    {
        var importer = (TextureImporter)AssetImporter.GetAtPath(SpritePath);
        importer.textureType = TextureImporterType.Sprite;
        importer.spriteImportMode = SpriteImportMode.Single;
        importer.spritePixelsPerUnit = 100f;
        importer.filterMode = FilterMode.Bilinear;
        importer.mipmapEnabled = false;

        var platformSettings = importer.GetPlatformTextureSettings("Android");
        platformSettings.overridden = true;
        platformSettings.format = TextureImporterFormat.ASTC_6x6;
        importer.SetPlatformTextureSettings(platformSettings);

        EditorUtility.SetDirty(importer);
        importer.SaveAndReimport();
    }

    private static void WireIntoPrefab()
    {
        var sprite = AssetDatabase.LoadAssetAtPath<Sprite>(SpritePath);
        var prefabRoot = PrefabUtility.LoadPrefabContents(PrefabPath);
        try
        {
            var visual = prefabRoot.transform.Find("Visual");
            var renderer = visual.GetComponent<SpriteRenderer>();
            renderer.sprite = sprite;
            PrefabUtility.SaveAsPrefabAsset(prefabRoot, PrefabPath);
        }
        finally
        {
            PrefabUtility.UnloadPrefabContents(prefabRoot);
        }
    }
}
```
